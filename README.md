## Full Room Sniper

G-Earth extension to monitor room capacity and attempt to enter full rooms.

Requires [**.NET 8 Desktop Runtime**](https://dotnet.microsoft.com/en-us/download/dotnet/8.0) installed

- Usage: Press **Start** and try to join the room you want to target
